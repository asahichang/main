«Резонанс»: правила и описание для реализации
Карточная игра для 2–4 игроков, 15–20 минут. Идея: простые отношения периодов накапливают эффект. Что именно произойдёт, строит система или разрушает, зависит от фазы.
Часть 1. Правила
1.1 Состав колоды (60 карт)
ТипКол-воНазначениеТела41Строят систему, у каждого есть период 1–12Возмущения11Меняют уже лежащие картыЛюки8Зона опасности (щели Кирквуда) и защиты (Гильды)
1.2 Подготовка
1. Перемешайте колоду, возьмите верхнюю карту-тело, положите в центр стола фазой 0. Это начало системы (ряд карт).
2. Каждому раздайте по 4 карты. Остальное колода.
3. Рядом оставьте место под Зону Кирквуда (до 2 карт Люк) и запас жетонов «Нагрузка».
1.3 Фаза: главная механика
Положение тела на орбите показывает фаза, число от 0 до 3 (четверти оборота: 0°, 90°, 180°, 270°).
- Физическая версия: в углу карты-тела нарисована стрелка. Кладя карту, вы выбираете её поворот: стрелка вверх = 0, вправо = 1, вниз = 2, влево = 3.
- Цифровая версия: игрок выбирает одно из четырёх положений при выкладывании.
Для двух соседних тел с резонансным отношением периодов считается разность фаз Δ = (фаза A − фаза B) mod 4:
ΔНазваниеФизический смыслЭффект0СближениеТела сходятся в одной точке, толчки складываютсяОчки ×2 сейчас, но на связь кладётся жетон «Нагрузка» в конце каждого раунда1 или 3СдвигСближения идут в разных местахОбычные очки2ПротивофазаСближения происходят вдали друг от друга (Плутон и Нептун)+1 очко и защита: тело в фазе 2 не выбрасывается Люком
Нагрузка — это накопление толчков. Если на связи накопилось 3 жетона, орбита раскачана: тело с большим периодом выбрасывается из системы (при равных периодах правое). Если фаза в связи изменилась и Δ ≠ 0, жетоны снимаются.
Для несвязанных, диссонансных пар фаза ничего не меняет: они дают 0 очков и ничего не накапливают.
1.4 Таблица резонансов (базовые очки)
Отношение периодов приводится к несократимой дроби.
ОтношениеМузыкальный интервалОчки1:1Унисон12:1Октава23:1Октава + квинта23:2Квинта34:3Кварта3любое другоеДиссонанс0
Очки связи = базовые + модификатор фазы (Δ=0: ×2, Δ=2: +1, иначе без изменений). Для диссонанса всегда 0.
1.5 Цепочка и правило Лапласа
Три подряд идущих тела образуют цепочку, если обе их связи резонансные (базовые очки > 0). Пример: Ио, Европа, Ганимед (1:2:4) или Kepler-223 (3:4:6:8).
- Бонус цепочки равен сумме очков двух её связей (то есть эта сумма удваивается).
- Условие Лапласа: три карты не должны иметь одинаковую фазу. В настоящем резонансе Лапласа тройного сближения не бывает. Если фазы всех трёх равны, бонуса нет.
1.6 Ход игрока
1. Играете одну карту из руки:
  - Тело: положите к левому или правому краю системы, выбрав фазу (поворот). Сразу получите очки за новую связь и за новую цепочку, если она образовалась.
  - Возмущение: см. ниже.
  - Люк: положите в Зону Кирквуда. Если там уже две карты, самая старая уходит в сброс.
2. Возьмите карту до 4 в руке.
Очки получает тот, кто сыграл карту.

После возмущения вы получаете положительную разницу очков на затронутых связях: сумму по ним (после изменения) минус сумму (до изменения), если она больше нуля. Новые цепочки тоже считаются. Если тело выбыло из системы и ряд сомкнулся, образовавшиеся связи очков не приносят.
1.8 Люки (8 карт)
Зона Кирквуда вмещает до двух карт. Юпитер имеет период 12.
КартаКол-воДействиеЩель 2:12Выбрасывает тела с периодом 6Щель 3:12Выбрасывает тела с периодом 4Щель 4:12Выбрасывает тела с периодом 3Гильды 3:22Тела с периодом 8 защищены от любого Люка и приносят владельцу +1 очко при выкладывании
Люк действует в момент появления в зоне и в конце каждого раунда. Тело в фазе 2 не выбрасывается.
1.9 Раунд и конец игры
- Раунд заканчивается, когда все игроки сходили один раз. Тогда: (а) применяются Люки, (б) на все связи с Δ=0 кладётся по жетону «Нагрузка», (в) связи с тремя жетонами выбрасывают тело.
- Игра кончается, когда колода пуста и каждый игрок сыграл по ещё одному ходу. Побеждает набравший больше очков.

Часть 3. Описание для реализации
3.1 Рекомендуемый стек
Одностраничное веб-приложение без сборки: HTML, CSS, JavaScript (ES modules). Звук на Web Audio API. Хранилище не нужно. Режимы: хотсит (2–4 человека за одним экраном) и игра против бота.
3.2 Структура проекта

/index.html
/src/data/cards.js      // колода: тела, возмущения, люки
/src/engine/rules.js    // чистые функции: счёт, раунд, выбросы
/src/engine/state.js    // создание и переходы состояния
/src/engine/bot.js      // жадный бот
/src/ui/render.js       // отрисовка системы, рук, зоны
/src/ui/audio.js        // ноты и аккорды

Движок не знает про интерфейс: вход — состояние и действие, выход — новое состояние и список событий для анимации и звука.

Порядок в endRound: (1) применить все Люки из зоны, (2) для связей с резонансным отношением и Δ=0 добавить жетон, для остальных сбросить в 0, (3) для связей с loads >= 3 выбросить тело с большим периодом, (4) увеличить счётчик раунда. После каждого выброса индексы loads пересчитываются, и новым связям жетоны обнуляются.
Люк kirkwood выбрасывает тело, если effectivePeriod == hitPeriod и phase != 2 и не защищено Гильдой (период 8 при активной карте hilda).
3.5 Допустимые ходы
Для каждой карты в руке:
- body: позиция (левый или правый край) × фаза 0..3.
- perturb: выбор цели: любое тело (для tide ещё ±1, для phaseShift ещё ±90°), пара соседних (для swap).
- hatch: без параметров.
Бот и подсказки используют legalMoves и симулируют ход на копии состояния.
3.6 Интерфейс
- Система: горизонтальный ряд карт по центру. На карте крупно период, имя, иконка. Фаза нарисована как маленькая орбита с точкой в одном из четырёх положений.
- Связи: между соседями бейдж с отношением (например, 3:2), очками и нотой интервала. Цвет: зелёный — Δ=2, жёлтый — Δ=1/3, красный — Δ=0, серый — диссонанс. Жетоны нагрузки рисуются кружками под бейджем.
- Выкладывание тела: игрок выбирает карту, наводит курсор на край ряда и превью показывает очки для всех четырёх фаз. Колесо или кнопки меняют фазу. Это превью важно для понимания механики.
- Зона Кирквуда: отдельная панель сверху справа. Подсвечивает тела в системе, которым она угрожает.
- Подсказка факта: при наведении на карту показывается строка fact и физика связи.
- Журнал событий: одна строка на событие («Людмила выбросила тело периода 4: щель 3:1»).
3.7 Звук
Частота тела: f = 55 * 12 / period Гц. Тогда период 12 даёт 55 Гц (ля), период 6 даёт октаву, 4 даёт ещё квинту. Отношения совпадают с таблицей 1.4, поэтому резонансные пары звучат чисто, а периоды 5, 7 и 11 дают заметный диссонанс.
- При выкладывании тела проигрывается его нота (синус или треугольник, 0.5 с).
- При образовании связи звучат обе ноты вместе. Для диссонанса частота одной слегка отстроена (около 4%), слышны биения.
- Для Δ=0 добавляется короткое нарастание громкости, для Δ=2 мягкое затухание.
- Переключатель звука и режим «Ухо»: игрок выбирает ход, ориентируясь только на звук (карты скрывают номера периодов).
3.8 Бот
Жадная стратегия с оценкой риска:

для каждого допустимого хода:
    s = симулировать, получить дельту очков
    риск = число связей с Δ=0 (будущая нагрузка) * 1.5
    риск += число своих тел под действием Люка в конце раунда * 2
    оценка = s - риск
выбрать максимум (случайно среди равных)
Уровни сложности: лёгкий (случайный из топ-5), обычный (описанный выше), сложный (добавляет учёт хода противника по 1 ply).

3.10 Этапы разработки
1. Данные и движок: карты, rules.js, тесты. Ничего не рисуется.
2. Простой интерфейс: ряд карт, рука, выкладывание тела, счёт.
3. Фаза: выбор поворота, превью очков, нагрузка, выбросы.
4. Возмущения и Люки: все типы карт, зона Кирквуда, журнал.
5. Звук: ноты, аккорды, биения, режим «Ухо».
6. Бот и полировка: три уровня, анимации выбросов, подсказки с фактами.
3.11 Открытые решения для настройки баланса
- Нужна ли штрафная часть за выброс собственной карты (сейчас нет).
- Величина бонуса за Δ=2 (+1) и множителя Δ=0 (×2): подбирается по результатам тестовых партий.
- Количество карт Люк: если они слишком часты, партия превращается в чистку стола.
- Возможность вставки тела в середину ряда (сейчас только края).
