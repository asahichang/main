# Тесты (playwright-core + chromium/swiftshader)
 
Общее: все скрипты берут `../phobos-network.html`, three@0.128.0 отдают из `node_modules/three` (через page.route, сеть заблокирована), открывают страницу через setContent, ждут ~3.5 с и управляют астронавтом через отладочные хуки `window.__phobos` и `window.__astro` (start, A, SP, galFind, HALLS…). Автоматических «pass/fail» нет: скрипты печатают JSON/метрики, результат оценивается по ним и по скриншотам. В конце всегда печатается список page-ошибок — он должен быть пустым.
Запуск: положить скрипт в папку `t/` рядом с html и `node_modules`, затем `node test_X.js`. Пути к `/opt/pw-browsers/chromium` и `node_modules` при необходимости поправить.
 
## Триггерные фразы (тесты запускаются ТОЛЬКО по требованию)
- «**прогони smoke**» — test_smoke.js (около 1–1,5 мин; в отчёте только сводка PASS/FAIL, скриншоты сохраняются в файлы и не открываются без нужды).
- «**прогони тесты навигации**» — test_as12b, test_pin4, test_roof3.
- «**прогони тесты UI**» — test_map1, test_info.
- «**прогони всё**» — smoke + все точечные тесты.
Без такой фразы тесты не запускать. Исключение: после явной правки навигации можно прогнать один профильный тест и сообщить об этом.
| Файл | Что проверяет | Что считается успехом | Когда гонять |
|---|---|---|---|
| test_smoke.js | Общий дымовой тест: загрузка и хуки, скафандр в галерее, 3 маршрута (вход→пад, пад→галерея, g0→g1), карта, окна info, ошибки страницы | Все пункты PASS, «ИТОГ: ALL PASS»; эталон v33: ~72 с, загрузка ~21 с | По триггеру «прогони smoke», перед публикацией крупных версий |
| test_as12b.js | Ходьба скафандра по полосам в галереях: вход→пад, пад→вход, переход g0→g1 между галереями | Фаза доходит до arrived, путь идёт по полосе (v>0), нет остановок stuck и ошибок | После любых правок навигации, галерей, DOORS, stuck-guard |
| test_pin4.js | Красный Pin: выбор точки спавна в зале/на галерее, подтверждение, появление костюма | SP.ok/has = true, позиция на полу (floorSnap), корректная галерея, костюм встал на точку | Правки Pin, floorSnap, спавна |
| test_roof3.js | Посадка на крышу небоскрёба (Арес), спрыгивание, поход к цели на земле | Нет зацикливания вокруг здания, костюм спускается и доходит до цели | Правки descended(), planAny, stuck-guard, крыш |
| test_map1.js | Карта базы #amap в режиме скафандра | Карта рисуется, красная точка и стрелка на месте, клик выбирает объект | Правки карты mapData/mapDraw |
| test_info.js | Окна info (i): binfo, hinfo, a-info открываются отдельными окнами | Окна создаются, перетаскиваются/закрываются, нет ошибок | Правки makeInfoWin, панели баз |
| test_prog.js | Время загрузки и прогресс-лоадер | Печатает `ready` (мс) и метрики; ориентир ~13 с в swiftshader, лоадер minMs 2400 | Оптимизация загрузки, ленивая сборка |
| test_shots.js | Скриншоты галерей изнутри под разными углами | Визуальная проверка стен, концов, рамп, пола | Правки геометрии галерей и интерьеров |
 
Не покрыто тестами: подписи/метки, карточки небоскрёбов в списке объектов, кнопка «Взгляд» — проверять вручную.
